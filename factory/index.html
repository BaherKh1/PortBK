How one change gets made

  1. 1

    Triage

    An issue, an alert or a note from me becomes a written brief, or gets rejected with a reason.

  2. 2

    Build

    One agent takes one brief in its own copy of the code, so parallel jobs never collide.

  3. 3

    Review

    Agents that did not write the code check bugs, security, the brief and the path money takes.

  4. 4

    Merge

    I read the result and decide. Nothing ships, sends or spends without my approval.
